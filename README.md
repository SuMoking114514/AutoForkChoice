# 岔路自动选路（AutoForkChoice）

PVE 岔路口按**骰子剩余步数**推演落点，**只有落点正好停在疾行格（`MoveAgain`）上**才自动选方向，否则不动手。

## 为什么需要它

吉星派对的岔路口选方向是纯手工操作。想「踩到疾行再走一次」时，你得自己数格子——而且岔路不止一个，每张图都不一样。
本模组把这件事交给代码：按剩余步数把每个方向都算到底，只有真的能踩中疾行才替你点。

`LandType` 里哪个值是「疾行」也不是猜的——是用模组自己 dump 出的全图地块类型表，配合实机表现对出来的。

## 判定规则

每 80ms 检查一次：是否在战斗场景、是否轮到自己、是否处于选方向状态（`MoveArrowManager.IsSelectDir`）。

读 `Character.canStep` = **骰子剩余步数**（骰子点数 − 已走步数，游戏自己维护，代码里没有任何写死的步数）。

对每个方向箭头推演：

1. 第 1 步踏上该箭头指向的首格（`MoveArrow.EndLandId`）
2. 连走 `canStep` 步，得到落点
3. 途中**再遇到岔路不放弃**：取地块坐标，在分支里选「延续当前朝向」最直的那一支继续走
4. 走满后看落点：

| 落点情况 | 动作 |
| --- | --- |
| 落点 = `MoveAgain`（疾行） | **自动点这个方向** |
| 落点不是疾行 | 不选 |
| 中途被强制停车格拦下（起始点/补给站/商店/遗物） | 不选 |
| 断头路 / 取不到坐标导致无法推进 | 不选 |

**算不出确定结论就不动手**，方向交还给你自己选。

## 安装

把 zip 拖进 [AstralParty Toys](https://github.com/higashitaniyume/AstralParty.Toys) 的「导入 Mod」，
或解压得到 `mods\AutoForkChoice\`（内含 `AutoForkChoice.dll` 与 `AutoForkChoice.json`）。

**装完重启游戏**——加载器只在启动时读取 DLL。

## 配置

`mods\AutoForkChoice\config.json`，保存后热重载，无需重启。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `Enabled` | `true` | 总开关 |
| `TargetLandTypes` | `"MoveAgain"` | 目标落点地块类型，逗号分隔。留空 = 完全不自动选 |
| `StrictFinalLand` | `true` | 只认「正好走满剩余步数」的落点；`false` 时中途被强制停车格拦下也算落点 |
| `ClickCooldownMs` | `600` | 同一落点两次点击的最小间隔（毫秒） |
| `DebugLog` | `false` | 打印每个箭头的推演过程与全图地块类型表。排查问题时改 `true` |

## 地块类型对照

配置里写的是游戏内部 `LandType` 枚举名，**已用游戏日志实证**：

| 配置名 | 中文 | 说明 |
| --- | --- | --- |
| `MoveAgain` | **疾行** | 踩上去「再次行动」，就是疾行格 |
| `RollGold` | 金币 | 金币/掷金格 |
| `Born` | 起始点 | 出生/起始地块 |
| `Portal` | 传送门 | 随机传送到其他传送门 |
| `Monster` / `MonsterPursuit` | 怪物 / 怪物追击 | |
| `Event` / `Relic` / `Heal` / `DrawCard` | 事件 / 遗物 / 治疗 / 抽卡 | |
| `Pveshop` / `FillingStation` | 商店 / 补给站 | 停留格（会强制停） |

> `Pursuit` 是「追捕其他玩家」的战斗机制，**不是疾行**，别填。
> 想优先多个目标可以写 `MoveAgain,RollGold`。

## 版本记录

| 版本 | 变化 |
| --- | --- |
| **2.4.0** | 单路径推演 + 遇岔路取最直一支继续走；步数全程用运行时 `canStep`，不写死 |
| 2.3.0 | 改单路径，但遇下游岔路直接判「落点未定」放弃——过于保守，会导致该动时不动 |
| 2.2.0 | 从首格起再走 `canStep` 步且 BFS 枚举所有分支：①多走一步 ②把下游岔路当可随便拐，落点集合几乎必然含疾行 → 没踩到也乱点 |
| 2.1.0 | 加入诊断日志与全图地块类型输出 |
| 1.0.0 | 初版：只看箭头首格类型（只看眼前，落点全错） |

## 兼容性

- 插件 id `AutoForkChoice`，`permissions = 3`（`ReadGameState | GameActions`）——需要「操作游戏」权限才能替你点方向
- 只在**自己回合、且确实处于选方向状态**时动作，不会乱点
